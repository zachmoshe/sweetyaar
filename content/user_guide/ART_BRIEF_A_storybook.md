# SweetYaar parent guide: art brief, direction A "Storybook"

How this works
- Generate the images below, save them into the `art/` folder next to this file using the exact file names.
- Send me the folder (or just say "art is ready"). I rebuild the PDF and each image replaces its stand-in automatically; any file you skip keeps the stand-in.
- All images: no text, no letters, no logos, no UI. The guide adds all text itself.
- Generate at the sizes given (or larger, same shape). PNG preferred. Characters/props marked "transparent" should have a transparent background.

## Style prefix (paste before every prompt)

> Children's picture-book illustration, gouache and soft watercolour, visible paper grain, warm cream paper tones, rounded friendly shapes, gentle bedtime mood, muted teal, terracotta, mustard, sage green and soft peach palette, hand-painted look, no text, no letters.

## Recurring characters and props (keep identical in every image)

- **Teddy** (mascot): a small round honey-tan teddy bear, soft round ears with pale inner ears, cream muzzle, brown button nose, rosy cheeks, friendly. No clothes.
- **The speaker toy**: a small wooden cube with a round dark speaker grille with horizontal slits on the front, a small carved heart on the side, and a teal round button on top. Warm honey wood.
- **Light**: a tiny round glowing lamp-dot (used only where noted).

Generate the cover first. Use it as the style reference for every other image so the set stays consistent.

## Tips
- If a tool adds text or odd borders, regenerate or add "no text, no frame, no border".
- Keep Teddy and the speaker toy looking the same in every picture: reuse the cover or a Teddy image as a reference or style image if your tool supports it.
- Ask for 2 or 3 variations of each and pick the calmest. A little empty space in each picture is good.
